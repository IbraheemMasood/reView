How to read this

This graph shows which functions call which. Starting from main is the easiest way into any program.

  1. Click a function to read its decompiled C.
  2. Clicking also reveals its callers and callees.
  3. Work out what the small leaf functions do first.
  4. Then go back up and see how they combine.
  5. Red glow marks functions worth a closer look. It's a heuristic, and the sidebar says why.

    📖 Decompiler cheat sheettoggle
    • param_1, param_2… the arguments the function received, in order.
    • local_XX, iVar1, pcVar2… local variables. The prefix hints at the type (i = int, u = unsigned, pc = char pointer, s = size_t).
    • undefined8 8 bytes Ghidra couldn't type. Often a pointer or a long.
    • FUN_00101234 a function with no name. Rename it once you understand it.
    • in_FS_OFFSET + 0x28 the stack canary, a compiler safety check ending in __stack_chk_fail. Usually ignore it.
    • 0x21, 0x1505… hex constants. Convert to decimal and look them up, since some are famous.
    • "quoted strings" the best clues. Start there.
    • Decompiled code is a guess. Names and types are reconstructed, so the original source looked different.
